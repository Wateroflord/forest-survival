# Выживание в лесу

Что делать, если потерялся: укрытие, вода, огонь, ориентирование, сигналы, первая помощь, опасные животные и растения. Компас, SOS-фонарик азбукой Морзе, чек-лист снаряжения, экстренные номера и тест.

Экстренный номер в Европе и Украине — **112**. Приложение не заменяет спасателей: если потерялся, звони сразу.

## Установка

Приложение семейства **Winter Hub** (Android + Windows). Удобнее всего ставить и обновлять через Winter Hub, либо скачать файл из раздела **Releases**: `Forest-Survival.apk` для телефона, `Forest-Survival-Setup.exe` для ПК.

## Как устроено

Flutter (Dart). lib/content.dart — статьи, тест и чек-лист.

Сборку делает GitHub Actions при каждом изменении в `main`: анализ кода, тесты (`test/`), сборка APK и установщика для Windows, подпись постоянным ключом (общие скрипты в `winter-hub/ci`) и публикация в Releases.
